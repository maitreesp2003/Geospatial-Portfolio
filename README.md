# 📂 Featured Projects

## 🌡️ Urban Heat Island Assessment of Amreli District, Gujarat (2000–2025)

### Objective

To analyze long-term Urban Heat Island (UHI) patterns using Landsat satellite imagery and evaluate the relationship between land use change, vegetation, built-up areas, and land surface temperature.

### Tools Used

- Google Earth Engine
- ArcGIS 10.8
- Landsat Satellite Data

### Analysis Performed

- Land Use/Land Cover Mapping
- NDVI Analysis
- NDBI Analysis
- Land Surface Temperature (LST)
- Urban Heat Island (UHI) Mapping
